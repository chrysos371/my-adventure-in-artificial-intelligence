# AlexNet 论文复现与适配改进（CIFAR-10 版本）
## 项目简介
本项目基于《ImageNet Classification with Deep Convolutional Neural Networks》（AlexNet 论文）实现了网络结构的复现，核心目标是通过适配小规模数据集（CIFAR-10）完成 AlexNet 核心思想的落地实践，强化对卷积神经网络（CNN）核心结构的理解。

由于原始论文基于超大尺度的 ImageNet 数据集（1000 类、224×224 分辨率），受硬件和数据规模限制，本项目将数据集替换为 CIFAR-10（10 类、32×32 分辨率），并针对数据集特性对网络参数、预处理策略等进行了适应性调整，保留 AlexNet 核心设计思想的同时，保证模型在小数据集上的可训练性。

## 一、AlexNet 论文核心网络结构
AlexNet 是 2012 年 ImageNet 竞赛的冠军模型，首次将 CNN 推向深度化，其核心结构和创新点如下：

### 1. 整体网络架构
原始 AlexNet 共 8 层可训练层：**5 层卷积层 + 3 层全连接层**，核心设计如下：
| 层类型       | 核心参数（论文版）| 核心作用                     |
|--------------|------------------------------|------------------------------|
| 卷积层 1     | 11×11 卷积核，stride=4，64 通道 | 大卷积核提取粗粒度特征       |
| 池化层 1     | 3×3 池化核，stride=2（重叠池化） | 压缩特征，保留更多细节       |
| 卷积层 2     | 5×5 卷积核，padding=2，192 通道 | 中卷积核提取细粒度特征       |
| 池化层 2     | 3×3 池化核，stride=2           | 进一步压缩特征               |
| 卷积层 3-5   | 3×3 卷积核，padding=1          | 连续小卷积核深度提取特征     |
| 池化层 3     | 3×3 池化核，stride=2           | 最终压缩特征维度             |
| 全连接层 1-2 | 4096 神经元 + Dropout（p=0.5） | 特征组合 + 抑制过拟合        |
| 输出层       | 1000 神经元（适配 ImageNet）| 分类输出                     |

### 2. 核心创新点
- **ReLU 激活函数**：替代传统 Sigmoid/Tanh，解决梯度消失问题，加速收敛；
- **Dropout 正则化**：随机失活 50% 神经元，抑制过拟合；
- **重叠池化**：池化核步长小于核尺寸，避免特征信息丢失；
- **数据增强**：随机裁剪、水平翻转等，扩充训练数据；
- **双 GPU 并行**：拆分网络到双 GPU，提升训练效率（本项目未实现）。

## 二、代码中的适配与改进（CIFAR-10 版本）
为适配 CIFAR-10 数据集（32×32 分辨率、10 分类），代码对原始 AlexNet 进行了多维度调整，核心改进如下：

### 1. 数据集与输入尺寸调整
| 维度         | 论文版（ImageNet）| 代码版（CIFAR-10）| 调整原因                     |
|--------------|-----------------------|------------------------|------------------------------|
| 数据集       | ImageNet（1000 类）| CIFAR-10（10 类）| 降低数据规模，适配入门级硬件 |
| 输入分辨率   | 224×224               | 64×64（缩放后）| 避免小分辨率下卷积/池化后特征图消失 |
| 归一化参数   | ImageNet 均值/标准差  | CIFAR-10 专属均值/标准差 | 适配数据集分布，提升收敛效率 |

### 2. 卷积层与池化层参数调整
核心调整：缩小卷积核尺寸、降低步长、增加 padding，避免小输入尺寸下特征图过早消失：
| 层类型       | 论文版参数                | 代码版参数                  | 调整原因                     |
|--------------|---------------------------|-----------------------------|------------------------------|
| 卷积层 1     | 11×11，stride=4，padding=0 | 5×5，stride=1，padding=2    | 64×64 输入下，大卷积核/大步长会导致特征图过小 |
| 池化层 1-3   | 3×3 池化核，stride=2       | 2×2 池化核，stride=2        | 适配 64×64 输入的特征压缩节奏 |
| 卷积层 2     | 5×5，stride=1，padding=2   | 5×5，stride=1，padding=2    | 保留核心设计，适配通道数     |

### 3. 全连接层维度调整
由于输入分辨率和卷积层参数调整，卷积层输出特征图尺寸发生变化，全连接层输入维度同步调整：
- 论文版：卷积层输出 256×6×6 → 全连接层输入 9216；
- 代码版：卷积层输出 256×8×8（64→32→16→8 三次池化）→ 全连接层输入 16384；
- 输出层：从 1000 神经元调整为 10 神经元，适配 CIFAR-10 分类任务。

### 4. 权重初始化优化
- 论文版：卷积层/全连接层偏置初始化为 1；
- 代码版：偏置初始化为 0；
- 调整原因：小数据集下偏置初始化为 1 会导致初始损失过高，需更多训练轮次收敛，置 0 后初始损失更稳定。

### 5. 训练策略优化
| 维度         | 论文版策略                | 代码版策略                  | 调整原因                     |
|--------------|---------------------------|-----------------------------|------------------------------|
| 优化器       | SGD（动量 0.9）| SGD + 权重衰减（5e-4）| 小数据集易过拟合，权重衰减抑制过拟合 |
| 学习率调度   | 手动调整学习率            | ReduceLROnPlateau（验证集准确率为指标） | 自适应调整学习率，避免手动调参 |
| 数据增强     | 随机裁剪、水平翻转        | 随机裁剪（padding=4）+ 水平翻转（p=0.5） | 适配 64×64 输入的增强策略    |
| 训练轮次     | 超百轮                    | 40 轮                       | 小数据集收敛更快，避免过拟合 |

### 6. 其他细节改进
- 关闭 CUDA 相关警告，适配不同 GPU 架构；
- 加入训练时间监控，便于分析训练效率；
- 保存最优验证集准确率模型，避免训练后丢失最优结果；
- 可视化训练/验证损失、准确率曲线，直观分析训练过程。

## 三、项目运行说明
### 1. 环境依赖
```bash
torch >= 1.8.0
torchvision >= 0.9.0
matplotlib >= 3.4.0
numpy >= 1.21.0
torchsummary >= 1.5.1
```

### 2. 运行步骤
1. 克隆项目到本地；
2. 安装依赖包：`pip install -r requirements.txt`（需自行整理依赖）；
3. 运行 `Alexnet.py`：
   ```bash
   python Alexnet.py
   ```
4. 运行后自动完成：
   - 下载 CIFAR-10 数据集并预处理；
   - 初始化 AlexNet 模型并部署到 GPU/CPU；
   - 训练 40 轮，输出每轮训练/验证损失、准确率；
   - 保存最优模型（best_model.pth）；
   - 绘制损失/准确率曲线（代码中可视化部分需补全后生效）。

## 四、核心结果说明
1. 训练目标：在 CIFAR-10 数据集上实现稳定收敛，验证 AlexNet 核心思想的有效性；
2. 关键指标：训练过程中监控训练/验证损失、准确率，最优模型以验证集准确率为指标保存；
3. 预期效果：40 轮训练后，验证集准确率可达 75%+（受硬件、随机种子影响略有波动）。

## 五、总结
本项目保留了 AlexNet 的核心设计（5 卷积+3 全连接、ReLU、Dropout、重叠池化），通过适配 CIFAR-10 数据集完成了轻量化复现。核心改进围绕“小数据集适配”展开，解决了原始结构在小分辨率输入下的特征丢失、过拟合等问题，是理解深度 CNN 核心设计的入门级实践。

通过本项目可直观理解：
- 卷积核尺寸、步长、padding 对特征图尺寸的影响；
- 正则化策略（Dropout、权重衰减）对过拟合的抑制作用；
- 数据增强、学习率调度对小数据集训练的优化效果。
