## 📚 学习领域 & 内容规划
### 1. 机器学习&深度学习基础
- 核心内容：线性代数、微积分、概率论等AI必备数学基础；线性回归、逻辑回归、决策树、SVM等经典机器学习算法；神经网络、CNN、RNN/LSTM、Transformer等深度学习核心原理
- 仓库对应：算法手撸实现、数学基础笔记、经典论文复现、数据集练习demo

### 2. 自然语言处理（NLP）
- 核心内容：文本预处理、词向量（Word2Vec等）、序列模型、Seq2Seq架构、Transformer、BERT微调、大模型应用开发、RAG检索增强生成
- 仓库对应：分词器实现、文本分类/机器翻译等入门项目、NLP经典模型复现、大模型应用demo

### 3. 计算机视觉（CV）
- 核心内容：卷积神经网络，ALexnet,Resnet,Yolo,视觉transformer

### 3. 嵌入式AI & 边缘计算
- 核心内容：STM32开发、ARM架构基础、FreeRTOS实时系统、传感器与外设驱动、模型轻量化、端侧模型部署、智能车/机器人AI应用
- 仓库对应：STM32工程代码、RTOS学习笔记、端侧部署demo、硬件项目完整记录

### 4. 大模型应用开发
- 核心内容：LangChain框架使用、Agent智能体开发、Prompt工程、RAG落地实战、大模型API二次开发
- 仓库对应：框架练习代码、RAG完整项目、Agent demo、Prompt优化笔记

### 5. AI工程化 & 全栈基础
- 核心内容：Linux系统操作、Python/C/C++工程开发、前后端基础、Git版本管理、Docker容器化、模型部署落地
- 仓库对应：环境配置笔记、部署脚本、全栈demo、工程化最佳实践
